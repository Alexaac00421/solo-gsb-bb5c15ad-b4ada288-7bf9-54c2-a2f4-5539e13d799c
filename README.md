# 定向赛计时裁决台

面向小型定向赛的**离线**网页计时裁决台：Node.js + SQLite（sql.js，纯 JS/WASM，无需原生编译链与外部服务），单容器即可运行。

## 功能

- **赛前录入**：按序且不重复的检查点（末项为终点）、选手编号、带时区发枪时刻。
- **CSV 导入**：每行 `事件号,选手编号,检查点,带时区刷卡时刻`。整批校验：
  - 事件号 + 同内容重传 → 幂等跳过，不产生重复；
  - 同号异内容、未知选手 / 检查点、缺时区 / 格式错误 → 指出全部出错行号并**拒绝整批**。
- **成绩计算**：按刷卡时刻为每人依次选取「发枪后、前一点之后」各检查点的最早有效记录；重复 / 乱序记录保留供复核；缺任一点标记未完赛；完赛成绩 = 终点时刻 − 发枪时刻；按 **耗时 → 终点时刻 → 选手编号** 排序。
- **裁判作废**：可作废 / 恢复单条误读记录，成绩即时重算。
- **发布冻结**：发布时冻结榜单及所据事件全集；后续补传或作废只影响下次发布；历史榜单可随时回看。
- **一致性**：导入、作废、发布并发时结果对应同一已提交事件集，失败不留部分状态（见下文「并发与事务」）。

## 快速开始

### 方式一：Docker Compose（推荐，一键启动）

```bash
docker compose up --build
```

访问 **http://localhost:8080**（网页端口 8080）。

停止并保留数据：`docker compose down`；连数据一起删：`docker compose down -v`。

### 方式二：Docker

```bash
docker build -t orienteering-timer .
docker run -d --name orienteering-timer -p 8080:8080 -v timer-data:/app/data orienteering-timer
```

### 方式三：本地 Node.js（≥ 20）

```bash
npm ci
npm start          # http://localhost:8080
```

数据库文件首次启动时自动初始化（幂等建表），无需手动迁移。

## 配置（环境变量）

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `8080` | 网页监听端口（Compose 中改 `ports` 左侧可换宿主机端口） |
| `DB_PATH` | 容器内 `/app/data/timer.db`，本地 `data/timer.db` | SQLite 数据库文件路径（标准 SQLite 格式，可用 `sqlite3` 命令行查看） |

## 使用流程

1. **赛前录入**（`/setup`）：填发枪时刻（必须带时区，如 `2026-10-07T09:00:00+08:00`）、检查点（每行一个、按顺序、末行为终点）、选手编号（每行一个）。
2. **导入**（`/import`）：粘贴 CSV 或选择文件。示例：

   ```csv
   event_no,bib,checkpoint,punch_time
   e1,101,C1,2026-10-07T09:10:00+08:00
   e2,101,FIN,2026-10-07T09:40:00+08:00
   ```

   首行表头可省略；刷卡时刻必须带时区（`+08:00`、`+0800`、`Z` 均可）。
3. **复核**（`/events`）：查看每条记录的采用状态（采用·第 N 点 / 未采用 / 已作废），对误读记录执行作废或恢复，成绩即时重算。
4. **实时成绩**（`/results`）：当前榜单预览，随导入 / 作废即时更新。
5. **发布**：在实时成绩页点击「发布当前榜单」，冻结本期榜单与所据事件；在「发布历史」（`/publications`）回看任意一期，后续变更不影响已发布内容。

## 并发与事务

- 单进程内所有写操作（导入 / 作废 / 恢复 / 发布 / 设置）包在 `BEGIN IMMEDIATE … COMMIT` 事务中，同步串行执行，互不交错；
- 任一步失败整体回滚，且只有 COMMIT 成功后才将库文件落盘（临时文件 + 原子 rename），**不留部分状态**；
- 发布在单个事务内完成「读取已提交事件集 → 计算榜单 → 写入快照」，保证冻结榜单与其所据事件严格对应同一已提交状态。

```bash
npm run smoke    # 端到端冒烟：录入→导入→幂等重传→拒批→作废→发布→回看，24 项断言
```

## 项目结构

```
src/server.js    Express 路由与页面装配
src/db.js        sql.js 初始化、事务与原子落盘
src/importer.js  CSV 整批校验与幂等导入
src/results.js   成绩计算（选点、未完赛判定、排序）
src/csv.js       CSV 与带时区时刻解析
src/views.js     服务端渲染页面
test/smoke.js    端到端冒烟测试
Dockerfile / docker-compose.yml
```
